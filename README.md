# bootdev-asteroids

Asteroids clone built with Python and Pygame.

## Files

- `main.py` - Entry point / game loop
- `player.py` - Player ship logic
- `asteroid.py` - Asteroid entity
- `asteroidfield.py` - Asteroid field management
- `shot.py` - Shot/bullet logic
- `circleshape.py` - Circle shape utility
- `constants.py` - Game constants
- `logger.py` - Event logging
